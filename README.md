# Portfolio-Project---Sports-Car-Data-Analysis
This repository contains the raw data files, clean data files and Juypter Notebooks (IPYNB and HTML) for the data analysis on sports cars. 

The project includes taking a raw data file (from Kaggle), cleaning and validating it. Then exploring and visualising the data using pandas and SQL. 

Contents
- `sports_car.csv`: the raw data file taken from Kaggle.
- `sports_car_clean.csv`: the cleaned data file (cleaned using pandas).
- `Sports Car Project - Cleaning Data`: both the IPYNB and HTML file of the cleaning process (Juypter Notebook).
- `Sports Car Project - Exploring Data`: both the IPYNB and HTML file of the exploration and visualisation process (Juypter Notebook).
- `Sports Car Project - SQL Explore`: both the IPYNB and NTML file of the SQL exploration of the data (Juypter Notebook).
- `sports car background.png`: image file used as background in tableua dashboard.
- `sports car dashboard.png`: image of the dashboard - dashboard can be found on Tableau public: [View the Tableau Dashboard](https://public.tableau.com/views/SportsCardashboard/Dashboard1)
